
### Olá, eu sou o Matheus Basilio 👋
 
## 🧑‍💻 Sobre mim
 
Sou Engenheiro de Software Full Stack com foco em back-end, construindo plataformas de pagamento, ERPs e sistemas de gestão pública com TypeScript, NestJS e React. Atuo no ciclo completo do produto — requisito, arquitetura, código, deploy e sustentação em produção.
 
Alguns resultados que já entreguei:
 
* Eliminei uma race condition crítica na geração de contratos (causada por um job em cron de 1 minuto), migrando o fluxo para processamento assíncrono em fila com retry — acabando com contratos duplicados.
* Reduzi em 90% as idas ao banco de dados no fluxo de geração de contratos, consolidando dezenas de consultas dispersas em uma única query.
* Implementei as esteiras de CI/CD dos sistemas com notificação automática no Discord, reduzindo o deploy de 10 minutos manuais para 2 minutos automatizados.
* Conduzi a migração de infraestrutura de VMs para Cloud Run, eliminando manutenção manual de servidores e gerando economia relevante de custo mensal.
* Construí do zero a aplicação que substituiu o webapp legado de uma plataforma de gestão pública de saúde, reduzindo o tempo de carregamento de 20s para 3s.
* Desenvolvi um sistema de gestão de OS que rastreia o gasto da empresa por fornecedor, ranqueando por custo-benefício e gerando 50% de economia em compras.
* 🔭 Atualmente: aprofundando Clean Architecture e DDD, com foco em sistemas escaláveis e sustentáveis a longo prazo
* 🌱 Explorando: aplicações com IA generativa e agentes de IA aplicados ao fluxo de engenharia
* 💬 Fale comigo sobre: NestJS, arquitetura de software, performance de banco de dados e IA aplicada

## 🛠️ Stack e ferramentas
 
**Back-end**
Node.js, NestJS e TypeScript como base principal, com Prisma e TypeORM para modelagem e acesso a dados. Experiência prévia com PHP (Laravel, Slim) em sistemas ERP/CRM.
 
**Front-end**
React, Next.js e React Native para interfaces web e mobile.
 
**Dados**
PostgreSQL, MySQL, MongoDB e Redis — com foco constante em performance de consulta.
 
**Cloud e DevOps**
Docker, GCP (Cloud Run), AWS, Cloudflare e esteiras de CI/CD com Git.
 
**Open source**
Publiquei no NPM a [nestjs-to-collection](https://www.npmjs.com/package/nestjs-to-collection), biblioteca que gera collections de Postman e Insomnia a partir do Swagger ou dos decorators de uma API NestJS.
